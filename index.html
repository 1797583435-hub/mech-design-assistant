倒角与圆角

倒角用于去毛刺与装配导向，圆角用于降低应力集中；以下为常用经验值

推荐轴肩圆角半径—

选用原则

  • 倒角 C：去毛刺、方便装配与搬运，常用 C0.5 / C1 / C1.5 / C2 / C2.5 / C3 / C5（C1 即 45°×1 mm）。
  • 圆角 R：轴肩、受力零件根部等应力集中部位必须用圆角；轴肩圆角 r ≥ (0.05–0.1)d，取标准 R0.5–R10。
  • 铸造 / 注塑件的内圆角应 ≥ 0.5 mm，外圆角一般 ≤ 3 mm，避免尖角应力集中与模具崩角。
  • 应力集中系数 Kt 随 r/d 减小而增大：轴肩过渡处圆角取大值可显著提高疲劳强度。

  • H7/g6 — 精密滑动配合（如机床导轨、分度机构）
  • H7/h6 — 定位配合，可装拆（如定位销）

  • H7/k6 — 过渡配合，定位精度高，可用木锤装配
  • H7/n6 — 过渡/小过盈，需压入，不可频繁拆装
