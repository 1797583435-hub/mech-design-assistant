# 机械设计助手（Mechanical Design Assistant）

面向机械工程师的离线设计工具箱：**选型计算、强度校核、SolidWorks 建模尺寸速查与公差配合查询**，纯前端实现，无需安装、无需联网，打开 `index.html` 即可使用。

![预览](preview.png)

## 功能模块

### 选型计算

| 模块 | 说明 |
| --- | --- |
| 电机选型 | 负载扭矩 / 转速 → 所需功率与推荐额定功率，伺服惯量匹配检查 |
| 减速机选型 | 减速比、所需额定扭矩（× 服务系数）与输入功率 |
| 同步带传动 | 节径、带长、带齿数、带速与中心距（含选用带长反算） |
| 滚珠丝杠 | 驱动扭矩、所需功率、临界转速与压杆稳定校核 |
| 气缸选型 | 理论 / 标准缸径、实际推力、耗气量与活塞杆压杆校核 |
| 直线导轨 | 额定寿命（km / 小时）与静载荷安全校核 |
| 滚动轴承 | 基本额定寿命 L₁₀ 与寿命小时数 L₁₀ₕ |

### 校核计算

| 模块 | 说明 |
| --- | --- |
| 梁计算 | 简支/悬臂梁 × 集中力/均布载荷，矩形、圆、空心圆、工字截面，输出弯矩、应力、挠度与强度校核 |
| 轴设计 | 按功率-转速（纯扭转）或弯矩-扭矩（弯扭合成）求最小轴径，支持给定直径校核 |
| 齿轮传动 | 分度圆直径、中心距、传动比、输出转速与扭矩 |
| 螺旋弹簧 | 刚度、变形量、曲度系数、切应力与安全校核 |
| 螺栓计算 | 按性能等级、直径与摩擦系数计算预紧力与推荐拧紧力矩 |

### 画图与建模

| 模块 | 说明 |
| --- | --- |
| 螺纹尺寸 | 公制粗牙螺纹底孔（D−P）、通孔（精/中/粗）、沉头孔、圆柱头沉孔、扳手与垫圈速查，附全规格表 |
| 倒角与圆角 | 倒角 / 圆角选用原则、常用系列与轴肩圆角推荐 |
| 拔模斜度 | 注塑 / 压铸 / 铸造拔模角推荐与偏移量计算 |
| 形位公差 | ISO 2768-mK 一般公差参考（线性、角度、直线度 / 平面度、垂直度） |
| 表面粗糙度 | 加工方式与使用场合的 Ra 参考 |
| 键槽尺寸 | 按轴径查 GB/T 1095 平键 b×h、槽深 t / t1 与推荐键长 |
| O 型圈沟槽 | 按线径与压缩率计算密封沟槽深宽 |
| 轴承配合 | 按工况推荐轴与壳体孔公差带 |
| 钣金折弯 | K 因子、折弯补偿 / 扣除、展开计算与设计规则 |
| 注塑 / 铸造结构 | 壁厚、加强筋与最小圆角推荐 |
| 热处理与硬度 | 常用工艺硬度表与 HRC / HB 近似换算 |
| 公差配合 | ISO 286 公差带查询（H/g/h/f/js/k/n/p/d/c），自动判定间隙/过渡/过盈配合 |
| 材料库 | 21 种常用金属与工程塑料的密度、弹性模量、屈服/抗拉强度，支持搜索与分类筛选 |
| 单位换算 | 长度、力、压力/应力、扭矩、功率、转速、温度 |
| 设计检查表 | 26 项设计评审清单，进度自动保存在本机浏览器 |

## 本地使用

直接用浏览器打开 `index.html`，或将整个文件夹放到任意 Web 服务器上访问。全部功能离线可用。

## 部署到 GitHub Pages

推送到 GitHub 后，开启 GitHub Pages 即可获得公网访问地址：

1. 在 GitHub 创建同名仓库并推送代码；
2. 打开仓库 **Settings → Pages**；
3. **Source** 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存；
4. 等待约 1 分钟后，访问 `https://<用户名>.github.io/mech-design-assistant/`。

> 仓库同时提供了 `.github/workflows/deploy-pages.yml`，如希望用 GitHub Actions 自动构建部署，可在 Pages 设置中把 Source 切换为 **GitHub Actions**。

## 注意事项

- 计算采用国际单位制（mm / N / MPa），适用于初步设计和方案论证。
- 简化模型未计入应力集中、疲劳、冲击、温度等修正；正式设计请按 GB/T 标准结合实际工况取安全系数。
- 材料数据、形位公差、粗糙度、拔模角等为典型参考值，以对应标准、厂家样本或实测数据为准。

## 技术说明

纯 HTML / CSS / JavaScript（原生 ES6），无构建步骤、无第三方依赖，浏览器打开即用；检查表进度通过 `localStorage` 保存在本机。
